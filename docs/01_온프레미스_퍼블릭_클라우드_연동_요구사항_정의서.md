## 1. 개요

### 1.1 목적

AIMS Cloud 포탈에서 다수의 마이크로 데이터센터(MDC)와 퍼블릭 클라우드(AWS, GCP, Azure, NCP 등)를
단일 인터페이스로 통합 관리하기 위한 연동 요구사항을 정의한다.

### 1.2 연동 전략

퍼블릭 클라우드 연동은 오픈소스 프로젝트 **Cloud-Barista**의 두 핵심 컴포넌트를 활용한다.
직접 CSP(Cloud Service Provider) API를 호출하지 않고, Cloud-Barista가 제공하는 통합 API를 통해 연동한다.

```
AIMS Backend ──REST──▶ CB-Tumblebug (오케스트레이션) ──▶ CB-Spider (드라이버) ──▶ AWS/GCP/Azure/NCP...
```

| 컴포넌트 | 역할 | 기본 포트 |
|----------|------|-----------|
| **CB-Spider** | 멀티클라우드 통합 드라이버. CSP별 API 차이를 추상화하여 단일 REST API로 제공 | 1024 |
| **CB-Tumblebug** | 멀티클라우드 인프라 오케스트레이션. CB-Spider 위에서 네임스페이스 기반 자원 관리 | 1323 |

### 1.3 지원 CSP

CB-Spider가 지원하는 퍼블릭 클라우드:

| CSP | 드라이버 | VM | VPC | Disk | NLB | K8s |
|-----|---------|----|----|------|-----|-----|
| AWS | aws-driver | O | O | O | O | O |
| GCP | gcp-driver | O | O | O | O | O |
| Azure | azure-driver | O | O | O | O | O |
| NCP | ncp-driver | O | O | O | O | - |
| NHN Cloud | nhn-driver | O | O | O | - | - |
| KT Cloud | kt-driver | O | O | O | - | - |

| Tencent | tencent-driver | O | O | O | - | - |
| IBM (VPC) | ibm-driver | O | O | O | O | - |
| OpenStack | openstack-driver | O | O | O | O | - |

## 2. 연동 요구사항 상세

### 2.1 클라우드 연결 관리

AIMS 포탈에서 퍼블릭 클라우드 계정을 등록하고 연결을 관리한다.

| ID | 요구사항 | CB-Spider API | 비고 |
|----|----------|---------------|------|
| CON-01 | CSP 드라이버 등록/조회 | `POST/GET /spider/driver` | 드라이버 플러그인 등록 |
| CON-02 | CSP 인증정보(Credential) 등록/조회/삭제 | `POST/GET/DELETE /spider/credential` | AccessKey, SecretKey 등 |
| CON-03 | 리전 정보 등록/조회 | `POST/GET /spider/region` | CSP별 리전/존 |
| CON-04 | 연결 설정(ConnectionConfig) 생성/조회/삭제 | `POST/GET/DELETE /spider/connectionconfig` | 드라이버+인증+리전 조합 |
| CON-05 | 연결 상태 검증 | `GET /spider/healthcheck` | 연결 유효성 확인 |

**연결 설정 구조:**
```json
{
  "ConfigName": "aws-seoul-conn",
  "ProviderName": "AWS",
  "DriverName": "aws-driver",
  "CredentialName": "aws-cred-innogrid",
  "RegionName": "aws-ap-northeast-2"
}
```

|----|----------|---------------|---------------|
| NET-01 | VPC 생성/조회/삭제 | `POST/GET/DELETE /spider/vpc` | #30 IP Pool 관리 |
| NET-02 | 서브넷 추가/삭제 | `POST/DELETE /spider/vpc/{VPCName}/subnet` | #30 IP Pool 관리 |

| NET-04 | 보안그룹 규칙 추가/삭제 | `POST/DELETE /spider/securitygroup/{SGName}/rules` | #31 라우팅 |

```json
      }
    ]
  }
}
```

## 3. 온프레미스(MDC) 자체 연동 영역

아래 항목은 Cloud-Barista에 위임하지 않고 AIMS 자체 구현이 필요한 영역이다.

| 영역 | 연동 대상 | 프로토콜 | AIMS 요구사항 |
|------|----------|----------|---------------|
| VM 라이프사이클 | OpenStack / libvirt | REST / API | #18 |
| 물리 서버 모니터링 | IPMI / SNMP | IPMI 2.0 / SNMP v2c,v3 | #53 |
| 물리 디스크 관리 | 스토리지 컨트롤러 | REST / CLI | #28 |
| SAN Switch SFP | SAN 스위치 | SNMP / CLI | #33 |
| 랙실장도 | 자산관리 DB | DB 직접 | #36 |
| 모니터링 에이전트 | Prometheus + node_exporter | HTTP Pull | #52 |

## 4. AIMS ↔ Cloud-Barista 연동 데이터 흐름

### 4.1 VM 생성 흐름

```
사용자 ──▶ AIMS Frontend
              │
              ▼ POST /api/v1/vms
        AIMS Backend
              │ ① 카탈로그/권한 검증
              │ ② 요청 데이터를 CB 형식으로 변환
              ▼
        CB-Tumblebug
              │ POST /tumblebug/ns/{nsId}/infra
              ▼
         CB-Spider
              │ CSP별 드라이버 호출
              ▼
          AWS / GCP / Azure ...
              │
              ▼ 생성 결과 반환
        AIMS Backend
              │ ③ 생성 결과를 AIMS DB에 저장 (자산 대장)
              │ ④ 미터링 시작 등록
              ▼
          응답 반환
```

### 4.2 모니터링 데이터 수집 흐름

```
[MDC]                                    [퍼블릭 클라우드]
 node_exporter ◀── Prometheus Pull        CB-Spider monitoring API
       │                                        │
       ▼                                        ▼
   Prometheus                            AIMS Backend (폴링)
       │                                        │
       └──────────────┬─────────────────────────┘
                      ▼
               시계열 DB (TimescaleDB / VictoriaMetrics)
                      │
                      ▼
               AIMS Backend (조회/집계)
                      │
                      ▼
                  대시보드 / 알람
```

## 5. 비기능 요구사항

| ID | 항목 | 요구사항 |
|----|------|----------|
| NFR-01 | 인증 | CB-Tumblebug Basic Auth → 추후 JWT 전환 검토 |

| NFR-03 | 재시도 | CB API 일시 장애 시 최대 3회 재시도 (지수 백오프) |
| NFR-04 | 에러 매핑 | CB 에러 코드를 AIMS 표준 에러 코드로 변환 |
| NFR-05 | 감사 로그 | 퍼블릭 클라우드 자원 변경 시 감사 로그 기록 |
| NFR-06 | 동시성 | 동일 자원에 대한 중복 요청 방지 (비관적 잠금) |
